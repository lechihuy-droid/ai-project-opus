# Spec Kit Clarify

Read the current specification and constitution. Ask only high-value questions, one at a time when user input is required. Turn answers into explicit specification text, examples, constraints, or acceptance criteria. Do not invent decisions silently or alter implementation code. Use `references/spec-kit-template.md` for canonical guidance.
