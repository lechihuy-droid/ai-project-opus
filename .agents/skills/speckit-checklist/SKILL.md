# Spec Kit Checklist

Review written artifacts, not imagined implementation. Check clarity, completeness, consistency, scope, testability, security, accessibility, failure behavior, migration safety, and rollback. Make each item pass/fail and report gaps separately. Use `references/spec-kit-template.md` for canonical guidance.
