# Spec Kit Specify

Create or update the feature specification. Separate user-visible behavior from implementation choices. Give each requirement an acceptance scenario or state why it cannot yet be verified. Capture assumptions, dependencies, open questions, and non-goals. Do not write production code. Use `references/spec-kit-template.md` for canonical guidance.
