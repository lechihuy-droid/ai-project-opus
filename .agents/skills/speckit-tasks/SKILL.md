# Spec Kit Tasks

Convert the plan into small tasks naming affected areas, behavior, and verification evidence. Order foundation, contracts, implementation, integration, and cleanup. Mark parallel work only when write surfaces do not overlap. Avoid vague tasks. Use `references/spec-kit-template.md` for canonical guidance.
