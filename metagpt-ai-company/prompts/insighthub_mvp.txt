Build the InsightHub Agent MVP from the existing SRS, user stories, and hackathon brief in this repository.

MVP scope:
- Upload/import local sample files for Jira-like issues, WBS Excel/CSV, meeting minutes, and GitHub activity.
- Reconcile Jira issues to WBS tasks by key and title.
- Detect schedule slippage, orphan Jira issues, untracked WBS tasks, missing dates, and quality risk signals.
- Generate a weekly project report with source traceability for every factual claim.
- Provide a review UI where a PM can inspect anomalies, edit narrative text, and regenerate sections.
- Export the final report to Markdown and DOCX if practical.

Constraints:
- Optimize for a hackathon demo, not enterprise production.
- Use mock/sample file connectors first; defer real Jira, Slack, Teams, and GitHub OAuth integrations.
- Keep setup simple and runnable locally on Windows.
- Prefer a small full-stack app or a self-contained local web app with a clear demo flow.
- Preserve the existing requirements documents and generated artifacts.

Definition of done:
- A user can run the MVP locally.
- A demo dataset can be loaded without external credentials.
- The app shows reconciled project status, anomalies, report draft, traceability links, and export output.
- Include a short README with setup, run command, and demo script.
