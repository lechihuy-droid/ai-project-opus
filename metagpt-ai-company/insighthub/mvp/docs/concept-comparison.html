InsightHub Reporting Co-pilot — So sánh 2 Concept

Web App (theo SRS/User Stories)  vs  GitHub Copilot trong VS Code  ·  FPT Japan AI Hackathon 2026  ·  2026-05-22

Tài liệu này so sánh cách đóng gói & giao sản phẩm InsightHub. Cùng một lõi xử lý (pipeline Python: gom dữ liệu → đối soát → bắt bất thường → tính facts → viết narrative → chặn số bịa → xuất file) — nhưng 2 cách "bọc" khác nhau cho người dùng cuối.

1"Reporting Co-pilot" là gì

Một phần mềm tự ráp bản nháp báo cáo từ dữ liệu dự án có sẵn, gắn nguồn cho từng con số, rồi giao PM duyệt-và-gửi. "Co-pilot" = lái phụ: nó soạn nháp, PM vẫn là người quyết và chịu trách nhiệm — khác "autopilot" tự gửi khách. Câu hỏi của doc này: lái phụ đó ngồi trong "buồng lái" nào?

2Hai concept

Concept A

Web App standalone

Kiến trúc mà SRS & User Stories mô tả.

  • PM mở trình duyệt, đăng nhập, upload file / nối API, bấm "Generate".
  • Frontend React + backend Python/Node + PostgreSQL + REST API.
  • UI review split-pane tự xây, citation bấm được, widget chat tự xây.
  • LLM gọi từ backend qua endpoint → cần API key (trả phí).
  • Deploy server: AWS/Azure/on-prem + secret manager + SSO/SAML + cron scheduler.
Concept B — chọn cho MVP

GitHub Copilot trong VS Code

Bộ "skill" nạp vào Copilot — không phải app rời.

  • PM mở VS Code, chat với Copilot (model Claude Sonnet).
  • MCP server (Python) + .vscode/mcp.json + file .github prompt.
  • UI review = chính VS Code; refine = Copilot Chat có sẵn.
  • LLM = license Copilot → không cần API key.
  • Không deploy: chỉ là file trong repo. Kèm CLI headless chạy mọi nơi.

7Kết luận

✅ MVP hackathon → Concept B (Copilot/VS Code)

Trong timebox 1 ngày, Concept B không chỉ ghi điểm cao hơn (gỡ lại tiêu chí 7/10/11 ~+8đ) mà còn tránh được điều kiện disqualify: pipeline + CLI đã chạy E2E. Không tốn API key. Câu chuyện "zero-key, chạy bằng license Copilot có sẵn" là điểm khác biệt khi pitch.

⚠️ Concept A (Web) — không vứt đi, để fast-follow

Web App là hình hài "sản phẩm thật" mà SRS/User Stories mô tả, và là thứ FPT cần để triển khai diện rộng (đa người dùng, RBAC, scheduled, portfolio). Brief §9 cho 3 tuần — nếu có thêm thời gian sau MVP, Concept A là đích v2. MVP = Copilot · v2 = Web.
