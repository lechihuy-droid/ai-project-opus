InsightHub Reporting Co-pilot — Architecture

FPT Japan AI Hackathon 2026 · Deliverable §7 Architecture Document · 2026-05-23

Sản phẩm: AI Reporting Co-pilot tự gom dữ liệu Jira / WBS / Slack / GitHub / biên bản họp, đối soát chéo, phát hiện bất thường, và sinh báo cáo trạng thái cho khách hàng — mặc định tiếng Nhật keigo, dịch toàn bộ nội dung nguồn đa ngôn ngữ.

Điểm khác biệt: chạy trong VS Code + GitHub Copilot (Claude Sonnet) — không cần API key LLM; dùng license Copilot doanh nghiệp đã được duyệt sẵn. Lưới an toàn: CLI headless template-only luôn chạy được không cần Copilot.

5Prompt / Agent Design

Anti-hallucination (cốt lõi)

  • Python deterministic tính TẤT CẢ số liệu (facts.build_facts) → object Facts kèm allowed_numbers + allowed_keys.
  • LLM (Copilot/Sonnet) chỉ viết văn xuôi quanh facts, không tự tính.
  • validate_report chặn: số / ticket key trong narrative phải ⊆ allowed_* → vi phạm = không xuất file.
  • Cổng cứng — vendor-agnostic, đổi LLM cũng không phá lớp này.

Ngôn ngữ & Dịch (CR-002)

  • Mặc định JP keigo (brief §3.4); EN/VN tùy chọn.
  • Copilot dịch toàn bộ văn bản nguồn (Jira summary, biên bản, anomaly description) sang ngôn ngữ báo cáo.
  • Giữ verbatim: ID, số, ngày, citation [system:ref].
  • Đường CLI template-only: i18n.py localize cấu trúc (title + label + cụm từ).

6Template Engine & Extensibility

Multi-templatetemplates/registry.yaml + --template <name>. Thêm template = thả .docx + 1 dòng registry, không sửa code.
Report types--type weekly|monthly|portfolio. Monthly thêm 3 section (phase_trend / budget_effort / quality_kpis). Portfolio aggregate N project.
Diff vs last reportSnapshot facts mỗi lần chạy → output/history/<date>.json; diff.md liệt kê thay đổi (brief tiêu chí 8).
Custom KPIPer-section facts có thể mở rộng qua schema.py (chỉ THÊM model, không sửa cũ).

8Security & Audit (brief §4 + §8 crit 10)

  • No LLM key: license Copilot lo runtime LLM. Endpoint Copilot Enterprise = đã được FPT duyệt sẵn (brief §4 "approved LLM endpoint").
  • Data connector secret: chỉ env var refs trong connections.yaml (auth: env:JIRA_TOKEN) — không hardcode. Phase 2 chuyển sang secret manager.
  • Audit log: mọi MCP tool call + mọi LLM call → output/audit_log.md (timestamp, tool, params).
  • Traceability: output/traceability.json map mỗi fact → source record ID. Citation inline [jira:KEY], render thành hyperlink trong DOCX/PDF/MD.
  • Confidentiality: file mode = data không rời máy. Phase 2 deploy tenant boundary.
