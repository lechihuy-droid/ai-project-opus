html-kit — Skill Design

Bản thiết kế cho skill sinh deliverable HTML structured (report · diagram · plan · so sánh).

2026-06-14 · Huy Le · SDD gate: SD

1. Mục đích & phạm vi

Một skill duy nhất sinh deliverable HTML structured thay cho markdown, ưu tiên deterministic + token-rẻ + nhất quán (McKinsey), có dark mode & print.

Ngoài scope: app tương tác phức tạp, HTML nhiều trang, framework (React…), animation nặng.

2. Kiến trúc — 2 lớp tách biệt

Lớp nội dung

LLM sinh semantic HTML + JSON diagram trong <main>. Đây là phần duy nhất thay đổi theo yêu cầu.

Lớp trình bày

Kit tĩnh, không sinh lại: styles.css (token + dark + print), diagram.js (JSON→SVG), template.html (khung).

Nguyên tắc lõi: LLM chỉ sinh nội dung; CSS/JS là hằng số link external → tiết kiệm token, output nhất quán, sửa brand 1 chỗ.

3. Data flow

Diagram này render từ JSON bởi diagram.js — dogfood chính kit.

5. Design decisions & trade-off

Quyết địnhVì saoĐánh đổi

Gộp 3 năng lực (html/diagram/plan) vào 1 skill1 chỗ maintain, khớp /htmlcontext skill dài hơn 3 skill tách

6. Rules bất biến

  • Không re-output styles.css/diagram.js ở chế độ linked.
  • Semantic HTML, tái dùng component class, không đẻ CSS mới.
  • Diagram JSON only, không vẽ SVG tay.
  • Màu = token var(--…), không hex.
  • Phân vân → đối chiếu demo.html.

7. Rủi ro đã biết

Chưa verify render bằng mắt trong session (thiếu browser headless) → mở demo.html để nghiệm thu dark mode + diagram.
