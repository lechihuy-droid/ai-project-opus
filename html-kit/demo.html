Approach Comparison — Token Storage

Option A — HttpOnly Cookie

Token stored in server-set cookie. XSS cannot read it.

Chosen
  • XSS-safe by default
  • Needs CSRF protection
  • Works on all browsers
Option B — localStorage

Token stored in browser JS. Simple to implement.

Rejected
  • Vulnerable to XSS
  • No CSRF concern
  • Easy to debug
