# Topic Example: Coding Agent Productivity

## Type

Research / Developer Productivity

## Core idea

Dữ liệu doanh nghiệp cho thấy coding agent có thể làm tăng output như số pull request được merge, nhưng nhiều output hơn chưa chắc đồng nghĩa với chất lượng hoặc business value cao hơn.

## Hook

> AI coding agent có thực sự tăng năng suất, hay chỉ tạo thêm nhiều code?

## Viewer payoff

Không chỉ đo số dòng code hoặc số pull request. Cần đo thời gian hoàn thành, lỗi phát sinh và giá trị đưa vào sản phẩm.

## Visual direction

```text
Without agent: 100 PR
With agent: 124 PR
But: More output ≠ More value
```

## Test objective

Đo mức quan tâm của audience developer và hiệu quả của data visualization.
