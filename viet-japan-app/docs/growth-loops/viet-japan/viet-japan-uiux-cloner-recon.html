Screen Specs

HOME / Owned Funnel Entry

Role: Explain value in seconds and route users into the lowest-friction action.

LayoutHero full-width, concise H1, one supporting sentence, primary CTA "Làm quiz N2 ngay", secondary CTA "Xem event sắp tới". Below fold: proof/trust strip, quiz preview, event preview, latest tips.
ComponentsTopNav, Hero, DualCTA, TrustStrip, QuizPreviewCard, EventPreviewCard, LatestTipsList, Footer.
BehaviorMobile bottom nav is persistent after first screen. Hero CTAs should remain visually stronger than nav. Event teaser can be time-sensitive but not replace quiz as default primary CTA.
AvoidNo feed, no community graph, no giant SaaS sidebar, no abstract brand-only hero.
QUIZ / Lucida Guest Flow

Role: Deliver value before signup, then convert signup through progress saving.

LayoutOne question card per view, progress bar at top, large answer options, minimal distraction, result screen at completion.
ComponentsQuizShell, ProgressBar, QuestionCard, AnswerOption, FeedbackPanel, ResultSummary, ReviewMistakes, SaveProgressPrompt, ShareResultCard.
BehaviorTap answer -> immediate feedback -> short explanation -> next. Login prompt appears only after result or when saving progress. Share appears after completion, never before first value.
AvoidNo forced account creation, no long multi-field setup, no noisy gamification before correctness/learning value.
EVENTS / Trust Layer

Role: Make event registration feel organized, transparent and safe for Vietnamese users in Japan.

ListEvent cards show date block, title, city/online, price/free, host, capacity or attendee signal, and registration state.
DetailCover image, title, date/time, location map/link, cost, host card, previous gallery, guest/seat signal, registration form, waitlist state, FAQ/contact, cancellation/refund note.
BehaviorSticky bottom CTA on mobile. If full, CTA becomes waitlist. Registration success should expose calendar add, share event, and profile enrichment only after success.
AvoidNo vague "DM us" registration as primary UX; no hidden fee; no anonymous organizer; no event page without proof of previous activity when available.
PROFILE / Progress, Relevance, Privacy

Role: Give users a simple place to see progress and actions without turning the product into a social network.

CoreName, avatar, email/provider, language preference, privacy/settings link.
ProgressLearning card: N2 progress, recent quiz, streak/milestone if enabled. Event card: registered/upcoming/past. Share card: achievements and referral link.
RelevanceOptional JLPT/visa/job/region prompt after quiz completion or event registration. Microcopy: "để gợi ý nội dung phù hợp hơn; bỏ qua nếu chưa muốn".
AvoidNo forced sensitive fields at signup; no public social graph; no over-detailed analytics shown to users.
TIPS / Media Hub With Knowledge Spine

Role: Build trust and SEO while routing readers back into quiz/event/profile loops.

HubFeatured guide, category blocks, latest updates, event-related articles, beginner path, search.
ArticleClear title, updated date, author/editor, category tags, TOC for procedure content, step list, related articles, CTA to quiz/event/profile where relevant.
BehaviorLocale-ready content model from day one. Allow Vietnamese-only initially, but keep route/copy architecture ready for ja/vi.
AvoidNo generic blog stream only; no undated procedure article; no AI-looking walls of text without structure.
ADMIN / Founder Cockpit

Role: Give one operator daily clarity without analytics fatigue.

WidgetsVisitors by source/medium/campaign, top landing pages, quiz starts/completions, signups, event registrations/waitlist, recent users, top tips, quick actions.
LayoutPlausible-like one-page dashboard first. Tables below charts. Sidebar acceptable here if admin grows, but beta can start with top tabs.
BehaviorUTM is invisible to user. Capture first touch and current session; display aggregate only. Add export later if operations require it.
AvoidNo PostHog-style deep product suite in beta; no vanity metrics without conversion context; no multi-level admin IA.

Copy & Trust Rules

Use

"Làm thử 3 câu N2 ngay"

"Lưu tiến độ của bạn"

"Host: tên, ảnh, mô tả ngắn, liên hệ"

"Bỏ qua nếu chưa muốn"

"Chia sẻ kết quả N2 của bạn"

Avoid

"Đăng ký để bắt đầu"

"Community/social feed"

"Liên hệ để biết chi phí"

"Cung cấp visa/JLPT/nghề để tiếp tục"

"Share để nhận thưởng"

Visual Direction

  • Density: marketing landing gọn ở Home, high-focus card flow ở Quiz, information-dense nhưng rõ ở Event/Admin.
  • Palette: neutral foundation, one warm trust accent, one learning/progress accent, restrained success/warning/error states. Không dùng one-note purple/blue gradient hoặc beige-only palette.
  • Typography: system sans hoặc font có Vietnamese/Japanese coverage tốt; line-height rộng cho article; button labels ngắn để fit mobile.
  • Mobile: bottom nav 5 mục, sticky event CTA, quiz answer targets lớn, no nested cards, no text overlap.
  • Trust: policy links visible in footer, login, profile privacy, event registration and account deletion flow.

  3. Login-after-value + save progress + baseline profile.
