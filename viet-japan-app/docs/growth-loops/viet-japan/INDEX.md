## Tracking Notes

- `ui-demo.html` is the base reference.
- `ui-demo-v2.html` is the newer visual direction.
- `ui-demo-mobile.html` mirrors the v2 skin with a mobile layout simulation.
- If you add another variant, keep the same naming pattern: `*-v3.html`, `*-mobile.html`, or `*-standalone.html`.

## Recommended Update Rule

When a new Viet Japan artifact is added:

1. Put it in this folder.
2. Keep the filename versioned.
3. Add one row here.
4. Do not overwrite older snapshots unless explicitly requested.
