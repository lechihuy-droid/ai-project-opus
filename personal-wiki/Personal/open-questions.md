# Open Questions

## Summary
This is the active research agenda for wiki conversations with Codex. New seed pages should matter only if they help answer one of these questions or create a better one.

## Key Points
- AI trends: Which agent patterns are becoming production-grade?
- Re-skill: What should Huy practice this week to become stronger as an AI-native operator?
- Investment: Which AI trends create durable business value rather than temporary excitement?
- Opus/Lucida: Which workflow should be automated or productized next?

## Why It Matters
Questions keep the wiki pointed at decisions. Without them, the system over-collects sources.

## Details
Current question buckets:

### AI Trend Questions
- Are coding agents moving from assistant to autonomous worker?
- Which eval, observability, and HITL patterns make agents safer in real workflows?
- Which open-source tools are becoming de facto workflow infrastructure?

### Re-skill Questions
- What should Huy learn to stay valuable as AI automates more implementation work?
- Which skills should become weekly practice: prompt design, evaluation, automation, product strategy, data workflows, or investment research?
- What small project can convert a trend into usable skill?

### Investment Questions
- Which companies or sectors benefit from agentic software development?
- Which AI infra constraints are persistent: compute, memory, inference cost, data quality, evals, security, energy?
- What AI adoption signals matter for Japan, Vietnam, and global markets?
