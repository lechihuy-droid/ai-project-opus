End-to-end use case

User mở Portfolio screen sáng 9:00 JST, xem giá → chạy Market Analyst → xem News.

Execute order — 9 steps

  • Step 1

    Clone wealth-management plugin → plugins/wealth-management/ ✓ done (2026-05-20)

  • Step 2

    Scaffold FINOPT: npm create vite@latest finopt -- --template react, copy investment-optimizer.jsx → src/App.jsx, install yahoo-finance2 axios ⬜ next

  • Step 3

    Refactor agents.config.js: 4 system prompt reference skill paths thay vì hardcode content ⬜

  • Step 4

    Build yahoo-proxy.js (Node/Express, port 5001) → quote API cho 7203.T, AAPL, etc. ⬜

  • Step 5

    Settings screen: input Claude API key (localStorage) + portfolio input (symbol/qty/avgPrice) ⬜

  • Step 6

    Wire News Sentiment → fetch http://localhost:8765/api/intel/simple ⬜

  • Step 7

    Deploy Vercel + iPhone Add-to-Home Screen ⬜

  • Step 8

    (Parallel) Register EDINET API key — manual tại disclosure2.edinet-fi.go.jp ⬜

  • Step 9

    (Defer) risk-manager custom skill — chờ FINOPT chạy thực tế rồi scope ⏸ later

Risks / open questions

Token cost

4 agent call Claude API daily. Mitigate: cache + chỉ call khi user mở screen.

monitor

API key exposure

Anthropic key trong localStorage = unsafe nếu phone compromise. Revisit khi deploy.

deferred

Skill drift

Skill markdown vs agents.config.js dễ lệch nếu manual copy. Mitigate: build sync script.

open

JPY/USD conversion

FINOPT hardcode 0.0067. Mitigate: fetch live rate từ exchangerate-api.
