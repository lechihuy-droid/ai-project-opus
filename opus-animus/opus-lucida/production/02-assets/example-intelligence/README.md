# Example Intelligence Bank

**Status:** Active draft  
**Role:** Reference bank for selecting natural, persona-fit examples across Lucida lessons

---

## 1. What This Bank Is For

This bank is not part of the critical lesson workflow.

It is a reference layer used when:

- skeleton examples feel too textbook;
- slide examples need stronger relatability;
- Vietnamese lines sound stiff;
- a lesson needs a better hook situation;
- shorts need a more current angle.

It should support:

```text
teaching clarity
exam transfer
real-life transfer
persona fit
natural Vietnamese
natural Japanese
```

---

## 2. What This Bank Must Not Do

Do not use the bank to:

- change grammar scope;
- override teaching truth in the skeleton;
- add a new lesson beat by itself;
- force a trendy situation into a weak grammar fit.

Core rule:

```text
Trend provides context.
Grammar logic decides the example.
```

## 4. Fast Usage Pattern

When building examples for a lesson:

1. Start from the grammar logic in the skeleton.
2. Check persona fit in `01-persona-map.md`.
3. Pull 3-5 situations from the evergreen or seasonal bank.
4. Filter by grammar affordance.
5. Draft example candidates.
6. Run example QA.
7. Store approved examples in the lesson folder if needed.

For LLM-assisted retrieval:

1. Filter by labels in `08-label-taxonomy.md`.
2. Follow the retrieval flow in `09-llm-retrieval-contract.md`.
3. Then inspect wording details.
