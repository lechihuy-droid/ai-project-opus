# Example Creation Process
**Status:** Active  
**Role:** Operational process for turning a grammar need into an approved example

---

## 1. Goal

This process exists to prevent a common failure mode:

```text
correct grammar
but unnatural Japanese / Vietnamese
```

---

## 2. Standard Flow

```text
Step 1  - Define grammar need
Step 2  - Define scene need
Step 3  - Retrieve candidate scenes
Step 4  - Draft Japanese natural lines
Step 5  - Draft Vietnamese public lines
Step 6  - Add Vietnamese support lines
Step 7  - Run naturalness QA
Step 8  - Run pedagogy fit QA
Step 9  - Approve primary / backup / support
Step 10 - Store in lesson-specific approved file
```

---

## 3. Step Details

### Step 1 - Define Grammar Need

Write:

```text
target grammar cluster
target grammar action
what confusion this example must solve
```

Example:

```text
Wake
correction + constraint
learner must feel the difference between not wanting and not being able
```

### Step 2 - Define Scene Need

Write:

```text
who is speaking
to whom
what is happening
what tension exists
why this scene matters
```

### Step 3 - Retrieve Candidate Scenes

Use:

- situation bank;
- labels;
- persona map;
- retrieval contract.

Return 3-5 scene candidates, not full examples yet.

### Step 4 - Draft Japanese Natural Lines

Write the line as if a real speaker in that scene would say it.

Do not write it as a grammar demonstration sentence first.

### Step 5 - Draft Vietnamese Public Lines

Write the line as if:

- a real learner would say it;
- or a real teacher would retell it out loud.

This line must sound spoken.

### Step 6 - Add Vietnamese Support Lines

This is the more literal line.

Use only for:

- form explanation;
- contrast explanation;
- answer key clarity.

### Step 7 - Run Naturalness QA

Check:

- Japanese scene/register naturalness;
- Vietnamese spoken naturalness;
- public line vs support line separation.

### Step 8 - Run Pedagogy Fit QA

Check:

- grammar logic fit;
- exam transfer;
- real-life transfer;
- trap value;
- minimal-pair value.

### Step 9 - Approve Roles

Each candidate becomes one of:

```text
primary spine
practical expansion
support example
shorts-only
reject
```

### Step 10 - Store

Store final outputs in:

```text
lesson-specific approved file
```

---

## 4. Lane Rule

For one lesson:

```text
1 primary spine
1 practical expansion
0-1 trend-aware support example
```

Do not approve multiple examples that do the same job unless one is explicitly a backup.
