## Naming Rule

Active teaching lane files use short step names:

```text
01-master-teaching-skeleton.md
02-script.md
03-slide-deck.md
```

Handoff and support files use descriptive action names:

```text
wake-script-requirements.md
01-review-script-content.md
04-review-slide-deck.md
wake-slide-qa-criteria.md
```

Archive files keep their older names unless they become active again.
