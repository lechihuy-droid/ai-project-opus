# Master Teaching Skeleton Template
**Status:** Template
**Role:** Single source of truth giua `topic` va `video / slide / script`

## 0. Muc tieu

File nay dung de giai quyet van de:

- `topic -> lesson` qua mo
- `script`, `slide`, `video` sinh ra lech nhau
- review bi chong cheo tren nhieu artifact

Tu nay, truoc khi viet script hoac deck, can co 1 `master teaching skeleton`.

No la:

- teaching core
- video structure core
- slide structure core
- script structure core

No khong phai script day du.
No khong phai slide deck.
No la khung master de sinh ca hai.
