QA Gates

The formal gate sequence currently used by Lucida. Later gates for worksheet, publish, and analytics can be added as the system matures.

Gate 1

Skeleton

Scope, FMU, traps, minimal pairs, worked example logic, worksheet promise.
Gate 2

Output Architecture

Slide count, order, beat roles, timing, worked example, diagnostic, CTA.
Gate 3

Slide Structure

Source link, role, on-screen, reveal states, script beat, teaching check.
Gate 4

Slide Design

Layout, components, hierarchy, motion notes, Lucida design alignment.
Gate 5

Script

Grammar, coaching tone, hook, worked example reasoning, CTA, audio readiness.
Gate 6

Slide / Script Sync

Numbering, role sync, narration vs on-screen, reveal order, non-interference with design.
