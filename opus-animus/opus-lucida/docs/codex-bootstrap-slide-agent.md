## Architecture — tóm tắt 1 dòng

```
Claude plans.  Node renders.  OD previews.  Playwright validates.
```

| Layer | Role | Tool |
|---|---|---|
| Claude | Planner + reviewer | Prompts + Write tool |
| Node | Compiler (deterministic) | `scripts/render-deck.js` + Mustache |
| OD MCP | Preview + inspection (READ-ONLY) | OD daemon |
| Playwright | Visual QA + frame export | Headless Chromium |

**OD MCP không gen slide.** OD MCP tools (`get_artifact`, `get_file`, `list_files`, etc.) toàn read-only. Production rendering = deterministic Node script. LLM không được trong render path (vi phạm NFR-005 reproducibility).

## Mission

Build `opus-lucida/apps/slide-agent/`:

```
Lucida skeleton.md + script.md (read-only)
  ↓ Claude Orchestrator (Mode 0..4, prompt-driven)
lesson.json + slide-plan.json (typed)
  ↓ Node Renderer (scripts/render-deck.js + Mustache)
final-deck.html (deterministic, byte-identical re-renderable)
  ↓ QA Loop (rule-based scripts + Claude teaching review)
qa-report.md → patches → revised final-deck.html
  ↓ Playwright export
production/00-active/<lane>/frames/*.png
  ↓ Existing audio + video pipeline (unchanged)
```

Test target: **Wake cluster** (`production/00-active/wake-cluster/`).

## 4 Mandatory artifacts (locked architecture)

## CI gate — must pass trước Phase H Step 21 (visual review)

```
1. validate-slide-plan.js           exit 0
2. render-deck.js                    exit 0  → final-deck.html
3. diff vs previous render           empty   (reproducibility)
4. check-overflow.js                 exit 0  (char budget per template)
5. export smoke test (Playwright)   exit 0  (HTML opens, 17 sections)
```

Nếu CI gate fail → fix trước khi sang Phase H visual review.
