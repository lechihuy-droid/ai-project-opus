# Full Flow Prompt

Use this prompt when giving the workflow to Codex, Claude, or another coding agent.

```text
You are building a Remotion vertical short video from a script.

Follow this staged workflow:

Stage 1: Mapping
- If raw sources are provided, first use source-ingestor-cleaner.
- Classify every source as content_truth, style_reference, embed_asset, context_only, or ignore.
- Produce clean-brief.json.

Stage 2: Mapping
- Use script-template-mapper.
- Use clean-brief.json if present; otherwise use the raw script.
- Split the cleaned script into intent-based scenes.
- Choose template archetypes.
- Output video-map.json.
- Do not write React yet.

Stage 3: Build
- Use remotion-video-builder.
- Read video-map.json.
- Implement or update Remotion components using a template registry.
- Keep layout deterministic.
- Use subtitles for narration.
- Render the video.

Stage 4: QA
- Use remotion-visual-qa.
- Export representative still frames.
- Check template fit, subtitles, overlap, arrows, safe areas, and visual density.
- Patch and re-render until major issues are fixed.

Style:
- Vertical 9:16.
- Dark AI tech.
- Warm orange glow.
- Clean subtitle bar.
- No raw HTML/CSS generated by LLM as content.

Input script:
{{script}}

Optional raw sources:
{{sources}}
```
