## Summary
Karpathy LLM Wiki Pattern is a method of using LLM to maintain a wiki as a knowledge base. It involves creating a wiki page for each topic and using LLM to ingest, query, and lint the wiki pages.

## Key points
- LLM reads raw documents and creates wiki pages
- LLM compiles knowledge into wiki pages for fast querying
- The pattern consists of three layers: raw, wiki, and CLAUDE.md
- Three core operations: ingest, query, and lint

## Details
The Karpathy LLM Wiki Pattern is based on the idea of using LLM to maintain a wiki as a knowledge base. It involves creating a wiki page for each topic and using LLM to ingest, query, and lint the wiki pages. The pattern consists of three layers: raw, wiki, and CLAUDE.md. The raw layer contains the raw documents, the wiki layer contains the wiki pages created by LLM, and the CLAUDE.md layer contains the schema file that defines the topics and tags.
