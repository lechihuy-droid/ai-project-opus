# LLM Wiki Agent Research and Build Plan

## Summary
The LLM Wiki Agent is a research project that aims to create a personal wiki using a large language model (LLM) as a research librarian. The LLM reads and processes input documents, creating and updating wiki pages, and linking them together.

## Key Points
- LLM Wiki is a persistent, compounding artifact
- It is a curated, maintained knowledge graph
- LLM Wiki has three main operations: ingest, query, and lint

## Why It Matters
The LLM Wiki Agent has the potential to revolutionize the way we manage and query knowledge. It can help us to build personal knowledge bases that are tailored to our specific needs and interests.

## Details
The LLM Wiki Agent uses a combination of natural language processing (NLP) and machine learning algorithms to read and process input documents. It creates and updates wiki pages based on the content of the input documents, and links them together to form a knowledge graph.

## Application To OPUS ANIMUS
The LLM Wiki Agent can be used to build a personal knowledge base for OPUS ANIMUS. This can help to improve the efficiency and effectiveness of the system, and provide a valuable resource for future research and development.
