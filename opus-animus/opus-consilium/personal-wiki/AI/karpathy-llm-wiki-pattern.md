# Karpathy LLM Wiki Pattern

## Summary
The Karpathy LLM Wiki pattern is a method for creating a personal wiki using a large language model (LLM) as a research librarian. The LLM reads and processes input documents, creating and updating wiki pages, and linking them together. This approach allows for efficient knowledge management and querying.

## Key Points
- LLM reads input documents and creates wiki pages
- Wiki pages are linked together for efficient querying
- The pattern consists of three layers: raw, wiki, and CLAUDE.md
- Three core operations: ingest, query, and lint

## Why It Matters
The Karpathy LLM Wiki pattern is important because it provides a method for creating a personal knowledge base that can be used to store and query knowledge. This can be useful for researchers, students, and professionals who need to manage large amounts of information.

## Details
The Karpathy LLM Wiki pattern is based on the idea of using LLM to maintain a wiki as a knowledge base. The LLM reads input documents, creates and updates wiki pages, and links them together. The pattern consists of three layers: raw, wiki, and CLAUDE.md. The raw layer contains the input documents, the wiki layer contains the created wiki pages, and the CLAUDE.md layer contains the schema that defines the structure of the wiki.
