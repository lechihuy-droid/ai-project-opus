# Re-skill Roadmap

## Summary
This page converts AI trends into skill decisions. It should answer what Huy should learn, practice, ignore, or turn into a project.

## Key Points
- The core direction is AI-native operator: design workflows, supervise agents, evaluate outputs, and productize useful systems.
- Skills should be practiced through Opus Animus and Lucida, not abstract courses only.
- Each weekly learning item should produce an artifact: script, workflow, SOP, evaluation checklist, dashboard, or thesis memo.
- 2026-05-20 priority: practice agent operations, not just prompting: task decomposition, trace review, sandbox boundaries, regression checks, context/memory hygiene, and final human approval.

## Why It Matters
AI trends only matter personally if they change the skill stack. This page keeps learning tied to practical leverage.

## Details
Skill lanes:
- Coding agents: task decomposition, review, tests, sandboxing, prompt contracts
- Workflow automation: pipelines, dashboards, file processing, scheduled jobs
- Evaluation: QA criteria, regression checks, human review loops
- Product thinking: convert internal workflows into repeatable products
- Investment research: thesis writing, signal tracking, risk framing
