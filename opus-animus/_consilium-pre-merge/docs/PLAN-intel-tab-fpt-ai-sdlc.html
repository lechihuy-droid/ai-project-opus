North Star

Intel tab is not a prettier article list. It is a daily decision cockpit for one question:

What changed in AI / competitors / software delivery that helps me sell or build AI-SDLC and FDE capability for FPT Japan?

Target Workflow

Stage Purpose Current Asset Upgrade
Collect Gather trusted raw signals. run_collect.py, tools/collect_tool.py Add source health, source tier dashboard, optional Reddit/X/YouTube later.
Normalize Make every item comparable. raw article markdown metadata Formal article schema with category, actors, signals, confidence.
Filter Drop noise before reading. goal_score, relevance FPT AI-SDLC/FDE score rubric with deterministic pre-score + LLM note.
Enrich Turn news into intelligence. api/intel.py heuristic enrichment LLM extraction: business impact, competitive threat, sales use, next action.
Report Daily synthesis in the app. Intel tab daily report chips Persistent report snapshots and weekly rollup.
Act Convert insight into output. wiki status pending/ingested Mark as used, save to wiki, create pitch note, track feedback.

FPT / AI-SDLC Bias

  • AI coding agents, dev productivity, software delivery automation.
  • Legacy modernization: COBOL, mainframe, migration, modernization ROI.
  • Enterprise proof: metrics, benchmarks, deployment stories, cost reduction.
  • Japan-specific signals: SIer movement, on-prem/private AI, compliance, local LLMs.
  • FDE relevance: customer problem, demo angle, integration path, objection handling.

Daily Report Shape

  1. Executive brief: 3 things that matter.
  2. Top 5 intelligence items.
  3. Product / funding / partnership / OSS / community signals.
  4. Actor map: OpenAI, Anthropic, GitHub, Google, Japanese SIers, FPT/SCSK.
  5. Why it matters for FPT Japan AI-SDLC / FDE.
  6. Recommended action today.

Implementation Phases

Phase Build Acceptance Check
Phase 1 Backend Intel model: categories, actors, signals, importance, recommended action. /api/intel/report?date=... returns enriched items and markdown-like report.
Phase 2 Intel UI: daily report chips, report panel, signal summary, article evidence links. Intel tab answers: what matters, why, what action.
Phase 3 LLM synthesis: business impact, FPT relevance, sales angle, confidence. Report is readable in under 3 minutes and has one concrete next action.
Phase 4 Action loop: save to wiki, mark used, create pitch note, weekly reflection. Insights become reusable assets instead of disappearing after reading.
Phase 5 Source expansion: Reddit/community, YouTube transcripts, competitor pages, GitHub releases. New source type plugs into collect pipeline without rewriting report logic.
