1 · SkillSpector là gì

Tool dòng lệnh do NVIDIA phát hành (Apache-2.0, ~9.4k★, v2.3.1), quét AI agent skills (Claude Code, Cursor, Codex CLI…) để phát hiện lỗ hổng, mẫu độc hại và rủi ro bảo mật trước khi cài. Bối cảnh: skill chạy với "implicit trust" và gần như không được vet — nghiên cứu của họ nêu 26.1% skill có lỗ hổng và 5.2% có dấu hiệu độc hại.

Đầu vào đa dạng

Git repo · URL · zip · thư mục · file .md đơn lẻ.

64 pattern / 16–18 nhóm

prompt injection, data exfiltration, privilege escalation, supply chain, excessive agency, rogue agent, MCP least-privilege, YARA signatures, taint tracking…

Phân tích 2 tầng

Static pattern nhanh + tầng LLM semantic tùy chọn để lọc ngữ cảnh.

SCA trực tiếp

Tra OSV.dev realtime cho CVE, có fallback offline.

Risk score 0–100

kèm severity + recommendation (SAFE / REVIEW / BLOCK).

terminal · JSON · Markdown · SARIF (vào CI).

3 · Cách cài & chạy

# Cài (Python 3.12/3.13)
git clone https://github.com/NVIDIA/SkillSpector && cd SkillSpector
uv sync --python 3.12          # hoặc: make install

# Quét 1 skill — static-only, xuất JSON
uv run skillspector scan ./my-skill/ --no-llm --format json -o report.json

# Quét + tầng LLM semantic (cần 1 trong các key)
export SKILLSPECTOR_PROVIDER=anthropic ANTHROPIC_API_KEY=...
uv run skillspector scan ./my-skill/ -f sarif -o report.sarif

Trong báo cáo này dùng --no-llm để không phát sinh chi phí và không gửi nội dung skill ra provider.

5 · Phân tích — vì sao điểm cao không có nghĩa nguy hiểm

False positive điển hình

  • Self-Modification: skill-creator/ppt-template-creator bị chấm HIGH vì có chữ "write/edit SKILL.md" — nhưng đó là nhiệm vụ của chúng.
  • Scope Creep: khớp cụm "not limited to" nằm trong LICENSE.txt (boilerplate Apache).
  • Autonomous Decision: khớp "without checking / without asking / No verification" trong văn bản khuyên cẩn thận.
  • Data Exfiltration: khớp URL API công khai đã ghi rõ trong docs.

Finding thật, nên xử lý

  • Làm Pin dependency trong dcf-model/requirements.txt: đổi >= sang == (hoặc thêm lockfile).
  • Cân nhắc Thêm field permissions: vào front-matter SKILL.md để tool và người đọc thấy rõ phạm vi quyền (3 skill thiếu).

Cả hai đều là vệ sinh tốt, không phải lỗ hổng khẩn cấp.

Bài học áp dụng: static-only có recall tốt nhưng precision thấp trên skill kiểu tài liệu. Điểm số chỉ nên dùng để chọn mục cần soi tay, không dùng làm cổng chặn tự động. Tầng LLM semantic (cần API key) sẽ dập phần lớn false positive trên — đây chính là lý do tool thiết kế 2 tầng.

7 · Giới hạn của lần chạy này

  • Static-only (--no-llm): không có tầng semantic → precision thấp như đã phân tích.
  • OSV.dev bị chặn outbound trong môi trường remote (cảnh báo SC4): SCA dùng static fallback, kết quả CVE có thể chưa đầy đủ. Chạy ở môi trường có mạng tới api.osv.dev để đủ dữ liệu.
  • Mới quét skill/agent/command nội bộ; chưa quét dependency tree sâu của từng script Python.
