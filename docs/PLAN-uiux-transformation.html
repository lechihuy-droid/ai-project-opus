0 · TL;DR

Opus Nexus đã đúng "xương" (4 view, bento, dark, mobile-first) nhưng vướng 3 nhóm vấn đề đo được, không phải gu cá nhân:

Blocker nền tảng

Touch target dưới chuẩn

Gần như mọi control < 44px iOS HIG: nav-tab ~32px, rtab ~28px, proposal-edit 30px → mis-tap trên phone.

Blocker nền tảng

Điều hướng & tone lẫn lộn

Nav top thay vì bottom tab bar; tới 3 tầng tab xếp chồng ở Vita; "Actions" mơ hồ; trộn Việt/Anh ("Today" vs "Sức khỏe").

Blocker nền tảng

Màu/typography quá tải

9 màu metric + status; --vita-good (green) gánh cả "active" lẫn "success"; body 12px / label 9–10px dưới ngưỡng đọc iOS (≥17px).

Cộng thêm: thiếu env(safe-area-inset-*) và meta PWA cho đúng use-case "bookmark iPhone". Plan đề xuất 3 phase, không refactor lớn, mọi thay đổi nằm gọn trong dashboard.html.

4 · Đề xuất transform

4.1 · Design tokens (sửa :root, dòng 14–64)
  • Type scale chuẩn: caption 11 / body 13 / title 15 / metric 28; bỏ 9px, nâng 10px → 11px tối thiểu.
  • Tách active vs success: thêm --vita-active riêng để gỡ green khỏi vai trò "active".
  • Touch token: --tap-min: 44px áp cho mọi button/tab.
  • Safe-area: env(safe-area-inset-*) vào topbar pad-top + content pad-bottom.
4.2 · Navigation
  • Chuyển primary nav xuống bottom tab bar (icon + nhãn, ≥44px, có safe-area) — đúng HIG cho phone.
  • Vita: gộp range-row thành segmented chip cuộn ngang trong content, không stack topbar.
  • Đổi nhãn "Actions" → "Duyệt"; thống nhất ngôn ngữ (Việt).
4.3 · Component polish
  • Snapshot Today: thêm progress (ring/pbar tái dùng) mỗi metric.
  • Actions: batch = primary, per-item = ghost; thêm Clear; approved rõ (✓ + "Đã thêm").
  • Calendar empty state: thêm CTA connect. Chuẩn hóa radius (card lg / nested md).
4.4 · PWA hygiene (đúng use-case bookmark iPhone)
  • Thêm meta apple-mobile-web-app-capable, apple-mobile-web-app-status-bar-style, theme-color; cân nhắc inline manifest. Không thêm CDN — chỉ meta tags.

5 · Phasing thực thi

  • Phase 1 — Foundation · rủi ro thấp

    4 blocker: type scale, tách active/success token, touch-target ≥44px, safe-area. Thuần token + CSS, không đổi DOM logic → kéo theo phần lớn friction.

  • Phase 2 — Navigation · rủi ro trung

    Bottom tab bar, gỡ stack tab Vita, đổi nhãn/ngôn ngữ. Phụ thuộc P1 (token, safe-area); đụng cấu trúc topbar + showView.

  • Phase 3 — Component polish · rủi ro thấp–trung

    Snapshot progress, Actions button hierarchy + Clear + approved state, calendar empty CTA, radius, PWA meta.

Verify mỗi phase: mở dashboard ở viewport 390–430px, kiểm 3 trạng thái (empty / có data / error), đo tap target ≥44px. Scope guard: không đổi nền/design language, không đụng JS API/validation, không thêm CDN (handoff §7).
