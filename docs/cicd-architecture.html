Quality Gate Architecture

3 gates, chạy tuần tự. Gate trước fail → không chạy gate sau (fail-fast).

Gate 1 — Lint

Ruff + Prettier + gitlint. <15s.

Fail → agent fix immediate

Gate 2 — Test

Pytest harness suite. <2min.

Fail → agent debug + fix

Gate 3 — Security

pip-audit + gitleaks. <1min.

Fail → block, escalate

Merge Allowed

All 3 pass → Claude merges.

# .github/workflows/test.yml name: CI — Test Suite on: push: branches: [main] paths: - harness/** - requirements*.txt pull_request: paths: - harness/** jobs: test: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-python@v5 with: python-version: '3.11' - name: Install deps run: pip install -r harness/hub/requirements-hub.txt pytest pytest-cov - name: Run tests run: pytest harness/hub/tests/ -x --cov=harness/hub --cov-fail-under=70 - name: Upload coverage uses: actions/upload-artifact@v4 with: name: coverage-report path: .coverage

Nightly Health Check

# .github/workflows/nightly-health.yml name: Nightly — Workspace Health on: schedule: - cron: '0 2 * * *' # 02:00 UTC daily workflow_dispatch: {} permissions: contents: read checks: read pull-requests: read jobs: health: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 with: fetch-depth: 0 - name: Stale branch report run: | echo "## Stale Branches (>7 days)" git branch -r --sort=-committerdate | while read branch; do age=$(( ($(date +%s) - $(git log -1 --format=%ct "$branch")) / 86400 )) if [ $age -gt 7 ]; then echo "- $branch: ${age}d" fi done - name: Dependency audit run: | pip install pip-audit pip-audit -r harness/hub/requirements-hub.txt || true - name: Full test suite run: | pip install -r harness/hub/requirements-hub.txt pytest pytest harness/hub/tests/ --tb=short || true - name: Upload report if: always() uses: actions/upload-artifact@v4 with: name: nightly-health-report path: health-report.md

# .github/workflows/stale-branches.yml name: Stale Branch Cleanup on: schedule: - cron: '0 3 * * *' # 03:00 UTC daily workflow_dispatch: {} jobs: cleanup: runs-on: ubuntu-latest permissions: contents: write steps: - uses: actions/checkout@v4 with: fetch-depth: 0 - name: Delete merged branches uses: pr-tab/delete-merged-branches@v1 - name: Report stale branches run: | echo "## Branches >14 days without activity" git for-each-ref --sort=-committerdate refs/remotes/origin/ \ --format='%(refname:short) %(committerdate:relative)' | head 20
