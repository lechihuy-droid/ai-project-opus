# 04. Resource Collector

## Mục tiêu

Sau khi topic được chọn, thu thập đủ nguồn đáng tin, demo và visual để tạo script và Business Input.

## Collector theo loại topic

### AI News

Official announcement → release notes/docs → báo uy tín → phản ứng cộng đồng → visual.

### GitHub Repo

README → docs → demo/GIF → releases → issues → use case → visual.

### Research Paper

Paper → abstract → phương pháp → kết quả → project page → implementation → visual.

### Office AI / Japan

Nguồn chính thức → use case thực tế → ví dụ công việc → hạn chế → cách áp dụng.

## Output mong muốn

- Topic summary.
- Why now.
- Verified claims.
- Main sources.
- Demo và visual assets.
- Suggested angles.
- Risks hoặc điểm chưa chắc chắn.

Collector không tạo script trực tiếp. Nó tạo Resource Pack để flow Create sử dụng.
