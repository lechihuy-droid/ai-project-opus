# Topic Backlog

Backlog được chia theo content pillar:

- `ai-news.md`: tin AI và chủ đề FOMO.
- `github-repos.md`: repo và AI tool đáng thử.
- `office-ai-japan.md`: tip dùng AI cho dân văn phòng tại Nhật.
- `ai-concepts.md`: khái niệm AI căn bản.
- `research.md`: paper và research insight.

Mỗi topic nên ghi tối thiểu:

- Topic.
- Vì sao bây giờ.
- Hook dự kiến.
- Người xem nhận được gì.
- Visual hoặc demo có thể dùng.
- Trạng thái: idea / selected / collecting / ready / published.
