Kết luận nhanh: NÊN THỬ Mức độ phù hợp CAO. Tool đọc trực tiếp log của Claude Code và Codex CLI — đúng 2 harness chính của bạn — chạy 100% offline, read-only, MIT. Hệ thống 45 rule anti-pattern editable bằng markdown ăn khớp với cách bạn đã làm việc theo rule (CLAUDE.md, lessons.md, Karpathy principles). Rào cản chính: là VS Code extension (bạn làm việc chủ yếu ở terminal CLI + Obsidian) và phải build từ source/VSIX, không phải sản phẩm Microsoft chính thức.

1. Đây là cái gì

VS Code extension phân tích session log cục bộ của các AI coding harness để chấm điểm và chỉ ra cách bạn đang dùng AI assistant tốt/dở ở đâu. Toàn bộ phân tích chạy trên máy bạn, không gửi dữ liệu ra ngoài. Triết lý: "observe → measure → improve → level-up".

Observe

Practice score 0–100, trend tuần/tháng, timeline session kiểu Gantt, gallery screenshot.

Measure

Lượng code sinh ra theo ngôn ngữ & model, heatmap 7×24 giờ làm việc, token budget.

Improve

45 rule anti-pattern (markdown + DSL), rule editor trực quan, skill finder, context health.

Level-up

XP/achievement Bronze→Diamond, quiz cá nhân hoá từ usage thật, stat card share được.

3. Ánh xạ trực tiếp với rule trong CLAUDE.md của bạn

Đây là điểm "apply" giá trị nhất — tool giúp đo lường mức bạn tuân thủ chính các nguyên tắc đã viết:

4. Rủi ro & điểm trừ

  • Khoá vào VS Code: nếu bạn chạy Claude Code / Codex chủ yếu ở terminal, phải mở VS Code chỉ để xem dashboard.
  • Không có trên Marketplace: phải tự build VSIX hoặc dùng Dev Container (cần Docker) → ma sát cài đặt + tự lo update.
  • Experimental, không bảo hành: không phải sản phẩm MS chính thức; một vài tính năng đang bị tắt.
  • AI features cần Copilot: rule compiler / skill finder / context review gọi VS Code Copilot LM API → cần Copilot license mới dùng được phần đó (các phần còn lại không cần).
  • Phụ thuộc format log: giá trị phụ thuộc parser bám đúng định dạng log của từng harness — có thể lệch khi harness đổi format.

5. Khuyến nghị apply

Cách thử rủi ro thấp (đề xuất):
  1. Tải VSIX prebuilt từ Releases → cài vào VS Code (1.115+), tránh phải build.
  2. Chạy "AI Engineer Coach: Open Dashboard", trỏ vào log Claude Code + Codex CLI có sẵn.
  3. Xem 5 practice score & danh sách anti-pattern trong ~1 tuần usage thật để xem signal có đúng không.
  4. Nếu hợp: customize rule trong .ai-engineer-coach/rules/ cho khớp Coding Behavior của bạn, và port các anti-pattern hay vào lessons.md / CLAUDE.md.

Ngay cả khi không dùng extension lâu dài, tập 45 rule anti-pattern (file markdown trong repo) đã là tài liệu tham khảo tốt để bồi đắp lessons.md và checklist review của bạn — đó là giá trị "apply" chắc chắn nhất, không phụ thuộc việc có chạy tool hay không.
