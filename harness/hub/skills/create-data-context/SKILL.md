# Create Data Context

Use this skill to make data meaning reusable across agents and analyses.

1. Inventory sources with owner, location, refresh behavior, and authority.
2. Define every table grain, primary key, time field, units, and lifecycle.
3. Specify joins with cardinality, allowed direction, and fanout protection.
4. Define metrics with formula, eligible population, time semantics, dimensions, and exclusions.
5. Record filters, caveats, known data quality issues, and conflicting definitions.
6. Establish source precedence and a review/update cadence.

Clearly label facts, validated definitions, assumptions, and open questions. Do not promote a draft metric to canonical without an owner and evidence.
