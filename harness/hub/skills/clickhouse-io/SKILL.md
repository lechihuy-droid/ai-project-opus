# ClickHouse Analytics

Use this skill for a ClickHouse data engineering or performance task.

1. Define event grain, retention, ingestion rate, query shapes, latency, and consistency needs.
2. Choose table engine, partition key, ordering key, and primary index from real access patterns.
3. Model deduplication, late data, updates, materialized views, and rollups explicitly.
4. Inspect parts, scans, query plans, memory, merges, and compression before tuning.
5. Validate reconciliation with the source system and expected query concurrency.

Never mutate a live cluster or change retention without approved scope, cost/impact evidence, backup strategy, and rollback or recovery plan.
