# Jupyter Notebooks

Use this skill to plan, author, or review a reproducible analysis notebook.

1. State question, environment, dependencies, inputs, versions, and data snapshot.
2. Organize cells from setup and validation through transformation, analysis, checks, and conclusions.
3. Make execution order deterministic; avoid hidden state and manual edits to intermediate values.
4. Keep secrets out of cells and outputs; parameterize environment-specific paths.
5. Add assertions for grain, row counts, nulls, reconciliations, and expected ranges.
6. Restart and run all cells before claiming reproducibility, then record export evidence.

Do not install kernels or packages unless an approved execution environment and pinned dependency plan exist.
