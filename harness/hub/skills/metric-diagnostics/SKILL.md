# Metric Diagnostics

Use this skill when a KPI changes unexpectedly.

1. Confirm the definition, source, freshness, pipeline health, and whether the change is real.
2. Quantify magnitude, onset, duration, confidence, and comparison baseline.
3. Decompose by metric identity and segment by the most plausible drivers without uncontrolled fishing.
4. Align changes with releases, campaigns, incidents, seasonality, and external events.
5. Rank hypotheses, state predicted observations, and test discriminating evidence.
6. Separate root cause, contributing factors, unknowns, and recommended monitoring.

Do not infer causality from correlation or stop at the first segment with a large absolute contribution.
