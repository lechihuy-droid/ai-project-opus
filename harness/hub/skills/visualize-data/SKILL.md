# Visualize Data

Use this skill to choose or critique a data visualization.

1. State the analytical question and comparison the reader must make.
2. Match chart form to task: position for comparison, lines for ordered time, distributions for spread, and tables for exact lookup.
3. Use truthful scales, units, ordering, denominators, and uncertainty.
4. Reduce decoration while preserving annotations that explain decisions or anomalies.
5. Provide accessible colors, labels, text alternatives, and readable responsive behavior.
6. Validate the chart against source values and edge cases.

Avoid pie charts for fine comparisons, dual axes without strong justification, and truncated scales that distort meaning.
