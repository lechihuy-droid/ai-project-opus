# Design KPIs

Use this skill when a team needs a measurable operating model.

1. Start from the outcome, decision, behavior, and time horizon.
2. Build a tree from north-star outcome through controllable drivers and diagnostic inputs.
3. Add guardrails for quality, risk, cost, fairness, and unintended optimization.
4. Define formula, population, exclusions, grain, dimensions, owner, cadence, and source for every metric.
5. Set target logic and alert thresholds with a baseline and review process.
6. Define instrumentation, data quality, and validation requirements before launch.

Reject vanity metrics and metrics that lack an action, owner, or stable definition.
