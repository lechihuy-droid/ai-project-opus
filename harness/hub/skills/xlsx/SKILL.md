# Spreadsheet Work

Use this skill for `.xlsx` analysis, generation, or delivery planning.

1. Define workbook purpose, sheets, table grains, units, date conventions, and source lineage.
2. Preserve formulas and formatting intentionally; never replace unknown formulas with values silently.
3. Separate raw inputs, transformations, checks, and presentation outputs.
4. Validate totals, formulas, references, filters, hidden rows, merged cells, and representative edge cases.
5. Require a rendered visual check for layout-sensitive delivery and a machine check for formulas/data.

Only use a spreadsheet tool bound by Hub. This text-only skill contains no upstream source-available assets or scripts.
