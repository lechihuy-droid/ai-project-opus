# Build Dashboard

Use this skill for KPI monitoring or analytical UI delivery.

1. Identify audience, decisions, review cadence, and actions the dashboard must support.
2. Define each KPI through approved semantic context before choosing visuals.
3. Create hierarchy from status and drivers to diagnostic detail; avoid equal-weight card walls.
4. Show freshness, filters, units, definitions, caveats, and drill paths.
5. Design loading, empty, stale, partial, permission, and error states.
6. Verify metric reconciliation, responsive layout, accessibility, and primary user journeys.

Do not claim a dashboard is trustworthy from visual polish alone; attach data and interaction evidence.
