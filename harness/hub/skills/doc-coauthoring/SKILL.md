# Document Coauthoring

Use this skill when a document must be shaped with the user rather than generated as a single draft.

1. Identify audience, decision, document type, required sources, and approval owner.
2. Agree on an outline and unresolved questions before drafting detail.
3. Separate verified facts, assumptions, options, decisions, and open risks.
4. Draft in reviewable sections and preserve user-provided terminology and constraints.
5. Run a reader test: can the intended reader decide or act without hidden context?
6. End with decisions, owners, evidence links, and next review gate.

This is a fresh Hub-native capability contract; it does not copy or redistribute source-available upstream document material.
