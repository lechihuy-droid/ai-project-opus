# Frontend App Builder

Use this skill to plan or implement a frontend application or dashboard.

1. Translate the objective into routes, user flows, data contracts, and acceptance criteria.
2. Reuse the repository framework, conventions, components, and state approach.
3. Implement the smallest vertical slice, including loading, empty, error, permission, and success states.
4. Keep server/client boundaries, secrets, caching, and mutation ownership explicit.
5. Verify typecheck, lint, build, focused tests, and the primary browser journey.

Do not scaffold a new stack or add dependencies unless the existing project cannot meet the requirement and the change is approved.
