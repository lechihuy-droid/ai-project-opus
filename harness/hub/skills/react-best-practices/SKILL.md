# React Best Practices

Use this skill when implementing or reviewing React code.

1. Keep components focused and derive state instead of duplicating it.
2. Put state at the lowest shared owner; distinguish server state, URL state, form state, and local UI state.
3. Use effects only for synchronization with external systems and make dependencies truthful.
4. Preserve semantic HTML, labels, focus behavior, keyboard access, and error announcements.
5. Measure before memoizing; address unstable identities, excess fetches, and large renders with evidence.
6. Test observable behavior rather than component internals.

Follow the installed React/framework version and repository conventions; do not invent APIs from a different release.
