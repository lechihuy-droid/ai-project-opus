## Hiện trạng (đã verify bằng đọc code)

`harness/hub/server.py:67-96` có middleware `_csrf_guard`. Với request không thuộc `{GET, HEAD, OPTIONS}` nó kiểm hai thứ:

1. Origin/Referer phải khớp `config.ALLOWED_ORIGINS` (`config.py:407-410`)
2. Header `config.HUB_CLIENT_HEADER` phải bằng `config.HUB_CLIENT_VALUE`

Vấn đề: `config.py:411-412` định nghĩa

```python
HUB_CLIENT_HEADER = "x-hub-client"
HUB_CLIENT_VALUE = "harness-hub"
```

Đây là hằng số nằm trong source công khai — bất kỳ process local nào đọc repo cũng gửi được. **Không có authentication thật nào trong toàn bộ app.** Mọi endpoint đổi trạng thái (tạo job, chạy agent, đăng ký hook shell) đều mở.

GET hoàn toàn không bị kiểm — kể cả `/api/fs/dirs` (duyệt thư mục toàn máy).

## Yêu cầu thay đổi

### 1. `hub/config.py`
- Xoá `HUB_CLIENT_HEADER`, `HUB_CLIENT_VALUE`
- Thêm:
  - `HUB_TOKEN_FILE = RUNTIME_STORE_DIR / "hub-token"`
  - `HUB_TOKEN` — load-or-generate: nếu env `HUB_TOKEN` có thì dùng; không thì đọc file; file chưa có thì sinh `secrets.token_urlsafe(32)`, ghi ra file với quyền `0o600` (dùng `os.chmod`, bọc try/except vì Windows có thể không áp dụng đầy đủ — **không** để lỗi chmod làm chết startup)
- Giữ nguyên `ALLOWED_ORIGINS`

### 2. `hub/server.py`
- Đổi tên `_csrf_guard` → `_auth_guard` (cập nhật decorator)
- Gate **mọi** method, không chỉ unsafe. Allowlist miễn auth: đúng 2 đường — `/api/health` và path bắt đầu `/static/`
- Token chấp nhận từ: header `X-Hub-Token`, **hoặc** query param `k`
- So sánh bằng `secrets.compare_digest`, không dùng `==`
- Sai/thiếu token → 403 qua đúng đường `_http_exception(...)` đang dùng, giữ format lỗi hiện tại
- **Giữ nguyên origin check** cho non-safe method (defense in depth, đừng xoá)

### 3. `hub/web-v3/src/lib/api.ts`
- Khi load: đọc `k` từ `location.search`; có thì lưu `sessionStorage.setItem('hubToken', k)` rồi xoá param khỏi URL bằng `history.replaceState` (để token không nằm lại trên thanh địa chỉ)
- `apiRequest` gắn header `X-Hub-Token` từ `sessionStorage`
- Giữ nguyên `ApiError` và cách xử lý lỗi hiện có

### 4. `hub/run-hub.ps1`
- Sau khi start, in ra console: `http://127.0.0.1:8799/?k=<token>`

### 5. `.gitignore` (root repo)
- Thêm `hub-token`

## Test phải thêm — `hub/tests/test_auth_guard.py`

Các case bắt buộc:
1. `GET /api/agent/runs` không token → **403**
2. `GET /api/agent/runs` sai token → **403**
3. `GET /api/agent/runs` đúng token qua header → **200**
4. `GET /api/agent/runs` đúng token qua `?k=` → **200**
5. `GET /api/health` không token → **200**
6. `POST` có token đúng nhưng Origin lạ → **403** (origin check còn sống)
7. `GET /api/fs/dirs` không token → **403** — case này chứng minh lỗ duyệt filesystem đã đóng
