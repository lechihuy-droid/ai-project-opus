# Spec Kit Analyze

Trace each requirement to a design decision, task, and verification. Find contradictions, orphan tasks, uncovered requirements, scope creep, missing constitutional checks, and untestable acceptance criteria. Classify critical, warning, or informational findings; stop on critical gaps. Use `references/spec-kit-template.md` for canonical guidance.
