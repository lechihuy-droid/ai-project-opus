# Codex Skill Stack

Portable 30-skill baseline for the Harness, registered as source `codex_stack`.

- Capability: Anthropic/Codex UI, web, document, spreadsheet, PDF, MCP, and skill-authoring skills.
- Execution: Superpowers planning, TDD, worktrees, subagents, review, delivery, debugging, and verification.
- Project lifecycle: eight `speckit-*` skills with source templates under each `references/` directory.
- Specialists: backend, API, PostgreSQL, and security.

Spec Kit owns WHAT; Superpowers owns HOW. Use at most one lifecycle skill per task. `speckit-plan` is architecture planning; `writing-plans` is optional implementation detail after `speckit-tasks`.
